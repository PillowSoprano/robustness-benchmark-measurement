# Reference sensitivity protocol — frozen 2026-09-15

Question: which model comparisons and baseline-exceedance boundaries survive changing the reference? The reference is common to the panel at each severity, not constant across severities. Pointwise ranking invariance is an algebraic property, not new empirical evidence of robustness.

References: persistence; mean of the available 20 observations; drift extrapolated from the first and last available observations; per-channel AR(1) with intercept, fitted on nominal training sequences only. AR(1) uses centered least squares with a fixed 1e-6 ridge penalty on the mean squared coefficient objective. No selection on test performance, no stability clipping, no ground-truth access after the origin. All references see the same corrupted observation history as the learned predictors. Nominal training normalization is reused. Reference roles are disclosed rather than selected after seeing results.

Retain the original model collection, seeds, information contract, horizons, severity grids and trajectory identifiers. TEP replay uses a fresh process for each simulation (Pool chunksize=1 and maxtasksperchild=1). Compare regenerated persistence errors to stored errors before reusing model errors; recompute saved models if necessary. Preserve the original files. TEP originals contain five seeds in some tables but only three in others; complete the saved MLP/GRU seeds through inference. Modern model results are stored as per-seed aggregate skill on a coarser grid: exact reference rescaling is permitted on that grid after matching the persistence numerator and population, but per-episode uncertainty cannot be recovered from those aggregates. Report that coverage explicitly; no fabricated weights or intervals.

Primary loss: reproduce MBR physical-unit mean-of-window RMSE and TEP training-standardized mean-of-window RMSE; also retain the alternative channel weighting in raw results. All models and references within a cell use one common, plant-defined validity mask. Nonfinite model predictions count as model failures. A TEP level is censored below 50% plant survival; survival is always reported. The original censoring rule concerns in-simulator trajectory validity, not clinical or industrial safety certification.

Report skill, raw model/reference losses, baseline crossings and censoring, nominal admission, training-seed spread, and changes in across-severity aggregation. Use 2,000 paired cluster bootstrap draws (seed 20260915): episode for TEP, parent trajectory for MBR; sample all windows within selected clusters together. Interpolation is descriptive between adjacent evaluated severities; a crossing is not inferred across a censored gap. Bootstrap replicates without crossings are reported separately from conditional finite-crossing intervals.

Interpretation: reference-sensitive utility boundaries narrow those claims. Fixed-population pointwise rank changes indicate an implementation/aggregation discrepancy. Stable rankings alone are guaranteed by the shared scalar reference and cannot validate the reference choice. Do not interpret skill<1 as intrinsic failure or skill>=1 as operational safety. Do not interpret normalized skill/clean skill as retained net advantage.

Full scope: both existing systems and their measured operators; all original core-model seeds; modern model comparisons on their originally published grid. Preserve separate mechanisms and task-design results for subsequent research. Work is complete only when new analyses, associated prose/figures, all reviewer responses, and the revision package are reconciled.
